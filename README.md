~Download the latest version of FSL from [here](https://www.unknowncheats.me/forum/grand-theft-auto-v/616977-fsl-local-gtao-saves.html) and place version.dll in your GTA V directory. Using FSL is now optional but highly recommended for account safety~

FSL NO LONGER WORKS WITH ENHANCED
  
1. Download YimMenuV2 from [GitHub Releases](https://github.com/YimMenu/YimMenuV2/releases/tag/nightly)
2. Download an injector, such as [Xenos](https://www.unknowncheats.me/forum/general-programming-and-reversing/124013-xenos-injector-v2-3-2-a.html)
3. Open Rockstar Launcher, select Grand Theft Auto V Enhanced, go to settings, and disable BattlEye. If you are using Steam or Epic Games, you may have to pass the -nobattleye command line parameter as well
4. Launch GTA V, then use your injector to inject YimMenuV2.dll at the main menu

## Common issues

### Can't join each other's sessions. (infinite loading)

if you're getting stuck on "Initializing" or "Joining GTA Online" enable Fast Join in Network tab then rejoin.

### Can't get out of missions or loadings

Just join another session in Network tab. Invite only is recommended cuz it's faster. (optional)
